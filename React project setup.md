# React Project Setup

## Project Name
**Online Doctor Consultation System**

## Description
The Online Doctor Consultation System is a web-based application developed using React.js for the frontend. It allows patients to register, log in, search doctors, book appointments, and consult doctors online. Doctors can manage appointments and patient records, while the administrator manages the overall system.

# Prerequisites

Install the following software before starting:

- Node.js (Latest LTS Version)
- npm
- Visual Studio Code
- Git

---

# Create React Project

Open Terminal and run:

```bash
npx create-react-app online-doctor-consultation-system
```

Move into the project folder:

```bash
cd online-doctor-consultation-system
```

---

# Install Required Packages

```bash
npm install react-router-dom
npm install axios
npm install bootstrap
```

---

# Start React Application

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
