# Working Application

## Module Name
**Working Application**

## Description

The Working Application module demonstrates the successful implementation of the Online Doctor Consultation System. It confirms that all major functionalities have been integrated and are working correctly from the frontend to the backend.

---

# Objective

The objectives of the Working Application are:

- Verify the complete system functionality.
- Ensure frontend and backend integration.
- Validate database connectivity.
- Confirm smooth user interaction.

---

# Application Workflow

1. User opens the application.
2. User registers as a Patient or Doctor.
3. User logs into the system.
4. Patient searches for available doctors.
5. Patient books an appointment.
6. Doctor views appointment requests.
7. Doctor updates appointment status.
8. Admin manages users and appointments.
9. User logs out successfully.
