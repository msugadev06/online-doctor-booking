# Frontend Review

## Module Name
**Frontend Review**

## Description

The Frontend Review module provides an overview of the user interface developed for the Online Doctor Consultation System. It ensures that all pages are responsive, easy to navigate, and provide a smooth user experience.

---

# Objective

The objectives of the Frontend Review are:

- Verify all frontend pages are working correctly.
- Ensure responsive design across different devices.
- Improve user experience and interface consistency.
- Confirm proper integration with backend APIs.

---

# Frontend Technologies Used

- React.js
- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- React Router DOM
- Axios

---

# Pages Reviewed

### Home Page
- Displays project introduction.
- Navigation to Login and Registration.

### Login Page
- Patient, Doctor, and Admin login.
- Input validation.
- Error messages for invalid credentials.

### Registration Page
- Patient registration.
- Doctor registration.
- Form validation.

### Dashboard
- Separate dashboards for Patient, Doctor, and Admin.
- Quick navigation to all modules.

### Doctor List
- Displays available doctors.
- Search and filter options.

### Appointment Page
- Book appointments.
- View appointment details.
- Cancel appointments.

### Profile Page
- View and update user profile information.
